Cpi Attendance - Windows PC/SC Reader Hardware Test v0.2 (Portable)
=====================================================================

วิธีใช้งาน Windows 10/11 แบบ 64 บิต
1) ดาวน์โหลดไฟล์ ZIP และคลิกขวา > Extract All (แยกไฟล์ทั้งหมด)
2) เปิดโฟลเดอร์ที่แยกออกมา (ห้ามเปิดไฟล์จากหน้าต่าง ZIP โดยตรง)
3) เสียบเครื่องอ่าน Zoweetek USB-C และเสียบบัตรประชาชนของตัวเองให้ถูกด้าน
4) ดับเบิลคลิก Start-Reader-Test.cmd
5) โปรแกรมจะแสดงรายการเครื่องอ่านและผล ATR แล้วหยุดรอให้ดูผล
6) ถ้าเครื่องอ่านแสดงตัวแต่ไม่อ่านบัตร ลองสลับด้านบัตรตามคู่มือ

แก้ปัญหาที่พบบ่อย
- แจ้งให้ติดตั้ง .NET: ไฟล์นี้เป็น Self-contained, ไม่ต้องติดตั้ง .NET เพิ่ม
- Windows protected your PC: ให้ตรวจสอบว่าไฟล์ได้มาจาก GitHub Actions ของโปรเจกต์จริง
  และ SHA256 ตรงกับ SHA256.txt ก่อนตัดสินใจเปิดใช้งาน ไม่ต้องปิดแอนติไวรัส
- เปิดโปรแกรมแล้วหาย: เปิดผ่าน Start-Reader-Test.cmd ซึ่งจะหยุดค้างหน้าต่างให้ดูผล
- Smart Card service error: กด Win+R > services.msc > Smart Card > Start (ถ้าหยุด)
- ไม่พบเครื่องอ่าน: ตรวจ Device Manager > Smart card readers และลองพอร์ต USB อื่น
- Windows 32-bit / ARM: รุ่นนี้ทำสำหรับ Windows x64 เท่านั้น
- ไม่ใช่ไฟล์ติดตั้ง .msi: โปรแกรมทดสอบเป็นแบบ Portable ไม่ต้องลงทะเบียนหรือติดตั้ง

ความเป็นส่วนตัว
- โปรแกรมนี้ตรวจเฉพาะเครื่องอ่านบัตรและสถานะ ATR ไม่อ่านชื่อ เลขบัตรหรือรูปภาพ
- ไม่ส่งข้อมูลไป Supabase, GitHub หรืออินเทอร์เน็ต
- ไม่ใช่โปรแกรม HR สำหรับใช้งานจริง และไม่ได้ยืนยันตัวตนเจ้าของบัตร
